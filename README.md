# Open Future+

Open Future+ is a youth-focused support website that helps students explore education, funding, career guidance, and opportunity pathways.

## Overview

This project is designed to support young people with practical next-step resources, including:

- APS calculator
- TUT course checker
- Study resources and guidance
- Funding information
- Opportunity and job links
- Founder and about information
- Help and support contact sections

## Tech Stack

- HTML
- CSS
- JavaScript
- Static website hosting

## Project Structure

- `index.html` – homepage
- `about.html` – about/founder page
- `students.html` – student tools and resources
- `opportunities.html` – jobs and opportunity information
- `style.css` – styling
- `script.js` – interactivity and page logic
- `assets/` – images and media
- `robots.txt` – crawler instructions
- `sitemap.xml` – sitemap for search engines

## Local Preview

Open the project in a browser using a local static server, or upload it to a static host such as Netlify or GitHub Pages.

## Deployment

This project is designed for static hosting and can be deployed on:

- Netlify
- GitHub Pages
- Cloudflare Pages
